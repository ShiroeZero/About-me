# SHIRO ✳ — An Unfinished Archive

Website pribadi sederhana untuk belajar HTML, CSS, dan publikasi dengan GitHub Pages.

## Struktur
- `index.html` — halaman utama, daftar tulisan, dan profil.
- `style.css` — seluruh desain; ubah variabel warna di bagian `:root`.
- `posts/awal.html` — contoh halaman artikel.
- `.nojekyll` — memberi tahu GitHub Pages untuk menyajikan situs statis secara langsung.

## Cara melihat di komputer
Download atau clone repository, lalu buka `index.html` dengan browser. Tidak perlu menginstal Node.js.

## Cara menerbitkan di GitHub Pages
1. Buka repository **ShiroeZero/About-me**.
2. Buka **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main**, folder **/(root)**, lalu **Save**.
5. Setelah GitHub selesai menerbitkan, URL situs: **https://shiroezero.github.io/About-me/**.

> Mengunggah kode tidak otomatis berarti GitHub Pages sudah aktif. Aktifkan di Settings → Pages.

## Latihan pertama
1. Ubah kalimat pembuka di `index.html`.
2. Ganti warna merah di `style.css` melalui `--red`.
3. Tulis ulang `posts/awal.html` dengan cerita sendiri.
4. Untuk menambah artikel, salin halaman contoh, beri nama file baru, lalu tambahkan tautannya ke `index.html`.

## Catatan desain
Terinspirasi secara umum oleh kontras, siluet, dan motif organik/geometris yang ditemukan dalam karya NanoMortis. Ilustrasi SVG pada website dibuat baru untuk proyek ini, bukan mengambil karya seniman tersebut.

Tidak ada framework, database, pelacak, atau aset pihak ketiga yang wajib dimuat.
